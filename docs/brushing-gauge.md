# ハブラシ・ジェット：磨く場所・磨き方・ゲージのしくみ

メインゲーム [mainapp.html](../mainapp.html) で、どこを、どの磨き方で、何秒磨くか、そして磨いた時間がどう記録されるかをまとめたものです。

- 磨く場所の番号①〜⑫は、参考資料「歯の磨き方.pdf」の順番と同じです
- 磨き方は micro:bit から届く値で判定します（`0`＝たて、`1`＝よこ、`2`＝ぐるぐる、`3`＝うちがわ）
- 場所は判定できないので、画面に「ここを磨こう」と文字と口の図で出します

モードは **BASIC（2分）** と **FAST（1分）** の2つです。

---

## 2. ゲージのたまり方

### 基本のルール

- 16種類（FASTは8種類）それぞれが「磨いた秒数」を持っています。必要な秒数に届いたら、その種類は選択肢に出なくなります
- ゲージはゲーム中は画面に出さず、裏で記録します
- micro:bit から磨き方の信号が届くと、そこから **0.6秒間** は「その磨き方をしている」とみなして、時間を足します
- 場所は判定できないので、**今出ている選択肢の中で、磨き方が合っているもの** に時間が入ります
  - 例：選択肢が「⑧よこ」と「④うちがわ」のときによこ磨きをすると、実際に磨いている場所に関係なく「⑧よこ」がたまる

### 1問の流れ（BASIC）

| 場面 | ゲージ | 時間の目安 |
|---|---|---|
| ① 問題が出て、まだ道を選んでいない | 磨いた磨き方の方にたまる。もう一方の選択肢の磨き方をした分もたまる | 2.5秒たまると道が決まる |
| ② 道が決まってからゲートまで | 選んだ方だけにたまる。磨いている間だけトロッコが進む | 残りの2.5秒で1セット（5秒）が終わる |
| ③ 正解・不正解の発表、次の問題まで | たまらない | ― |

- その種類の残りが2.5秒より少ないときは、②は残りの秒数だけになる。ただし短くても1.5秒は進む
- 手を止めてもトロッコはゆっくり進み、いつかはゲートに着く。その間はたまらない
- **間違えても、磨いた分はたまる**
- 時間切れのときは、それまでに磨いた分だけが残る

### 選択肢の決め方

- 2つは必ず違う磨き方にする（場所は判定できないため、磨き方で見分ける）
- 残り時間がいちばん多い磨き方と、2番目に多い磨き方から1つずつ出す
- 前の問題と同じ場所、2つの選択肢どうしで同じ場所は、できるだけ避ける
- 残りが1種類の磨き方だけになると、違う磨き方の2択が作れない。そのときだけ、もう終わった種類を出す。ここで必要より数秒多く磨くことがある

### フィーバータイム（問題が全部終わったあと）

- 残りを1セットずつに分けて、1つずつ「ここを みがこう！」と出す。BASICでは5秒、FASTでは7.5秒
- 必要な時間は「残りの秒数＋1秒」で、**正しい磨き方をしている間だけ** カウントが減る
- 磨かずに「必要な時間×3＋15秒」がたつと、次のセットに進む

---

## 3. 結果画面の数字

- **みがけた％**：それぞれの種類の秒数を必要な秒数で頭打ちにして足し、合計の必要な秒数（120秒、FASTは60秒）で割ったもの
- **みがいた時間**：多めに磨いた分も含めた、実際に磨いた時間の合計

## 4. 数字を変えたいとき

[mainapp.html](../mainapp.html) の中の次の場所を変えます。

| 変えたいもの | 場所 |
|---|---|
| BASICの場所・磨き方・秒数 | `makeTasks()` |
| FASTの場所・磨き方・秒数 | `makeFastTasks()` |
| 問題数・1セットの秒数（モードごと） | `MODES` の `totalQ` と `setSec` |
| 道が決まるまでの秒数 | `SELECT_SEC`（今は2.5秒） |
| 信号がとぎれても「磨いている」とみなす秒数 | `HOLD_SEC`（今は0.6秒） |
| フィーバータイムで足す秒数 | `FEVER_EXTRA`（今は1秒） |
| わかれ道までの時間 | `QTIME`（今は20秒） |

※ コードの注釈では、FASTの1セットが「6秒」と書いてありますが、実際の設定は `MODES` の `setSec: 7.5` です。
